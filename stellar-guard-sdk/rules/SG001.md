# SG001 — Storage mutation without authorization

| Field    | Value                                  |
| -------- | -------------------------------------- |
| Rule ID  | `SG001`                                |
| Severity | high                                   |
| Category | Access control                         |

## Description

Flags an entry point (a `pub fn` inside a `#[contractimpl]` impl block) that
mutates contract storage — persistent, instance, or temporary — without
first calling `require_auth()` or `require_auth_for_args()` on an `Address`
in the same function body.

Soroban's authorization model requires every state-changing entry point to
prove that the caller authorized the invocation. A write to
`env.storage().persistent()/instance()/temporary()` that is not preceded by
an authorization check lets any caller mutate contract state.

## Detection (v1)

The check is syntax-level and line-based:

1. Only `pub fn` items inside `#[contractimpl]` impl blocks are considered
   entry points.
2. Every method call in the body is inspected:
   - **Mutation** — a call named `set`, `put`, `remove`, `update`,
     `try_update`, `extend_ttl`, or `extend_ttl_with_limits` whose receiver
     chain starts from `env.storage()`, optionally through `.persistent()`,
     `.instance()`, or `.temporary()`.
   - **Authorization** — a call named `require_auth()` or
     `require_auth_for_args()`.
3. The function is flagged when a mutation appears with no authorization
   call on an earlier line.

See `LIMITATIONS.md` for the known v1 constraints (no control-flow or
dataflow analysis).

## Example

Vulnerable:

```rust
#[contractimpl]
impl VaultContract {
    pub fn withdraw(env: Env, caller: Address, amount: i128) -> i128 {
        // ... no caller.require_auth() anywhere ...
        env.storage().persistent().set(&balance_key, &new_balance);
        new_balance
    }
}
```

Safe:

```rust
#[contractimpl]
impl VaultContract {
    pub fn withdraw(env: Env, caller: Address, amount: i128) -> i128 {
        caller.require_auth();
        // ...
        env.storage().persistent().set(&balance_key, &new_balance);
        new_balance
    }
}
```
